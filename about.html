I don't write the code. I make sure it is right.

An AI generalist from Chhapra, Bihar: what the work actually is, how I started, why I took a Python course I never intend to use, and a running log of what I learned and when.

I'm an AI generalist. That is not a borrowed job title, it is what the work actually is: moving between prompt, context, loop and graph depending on what the job needs, and picking whichever free tool tests best for that job.

I started a year ago with ordinary chat. The first thing I built was my own agent: a scheduled worker that checks whether the job is actually done, creates follow-up tasks when it needs more time, wakes itself and keeps going, and writes notes into a GitHub repo so the next run starts with context instead of from zero. It ran on free models with no API key and cost me nothing.

I don't write code and I don't intend to. I direct it, and I took a Python course for one reason: so I can describe a job well enough that the AI cannot fill the gaps with guesses, read the structure it hands back, and catch its mistakes. A team leader who cannot do the work cannot get the work done. Same rule here.

For now I build for myself, not for clients. Feedfy is next: instead of scrolling for an hour to find content worth keeping, a feed that goes and finds it, in about two minutes.
