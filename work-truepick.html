TruePick — an affiliate storefront with an admin

A fully virtual affiliate shop: products with affiliate links, a blog that reads itself aloud, YouTube reviews on product pages, and a WordPress-style admin panel behind it on Netlify.

What it is

You add a product with its affiliate link, the site shows it, and every buy button sends the visitor straight to the store. No login on the storefront, no cart to maintain — the whole catalogue lives in three JSON files.

What is in the build

  • Nine pages — home with a banner carousel, catalogue with filters and sorting, product, blog, blog post, wishlist, account, about, terms.
  • Product pages that do work: a "good for these people" block, a plus-icon accordion, a callout, alternatives as pills, a details accordion, a rating widget, and embedded YouTube reviews with an average reviewer rating.
  • A blog that reads itself aloud, because not everyone wants to read on a phone.
  • The admin twin: a second, private repository (57 files, 11 pages) adds a WordPress-style panel at /co-admin with login, a drag-and-drop editor, and product, banner and blog management, running on Netlify Functions and Blobs. It is not public, so it is not counted on the card above.

What it taught me

Data outlives design. Because every product, banner and post is a JSON entry, the site can be re-skinned without touching content, and content can be added without touching code. It is also the reason the tools table on my home page is a data file: I learned it here.
